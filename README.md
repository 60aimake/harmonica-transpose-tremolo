# 반주(MR) 변경툴 — 트레몰로

반주 음원의 **조(키)를 바꾸거나, 빠르기만 바꿉니다.** 설치할 것이 없습니다.

👉 **https://60aimake.github.io/harmonica-transpose-tremolo/**

`v1.2.0` · 2026-11-21

---

## 무엇이 되나

| | |
|---|---|
| **조 바꾸기** | 반음 단위로 올리거나 내립니다. 빠르기는 그대로입니다 |
| **빠르기만 바꾸기** | 테이프를 빨리 감듯 바꿉니다. 음높이도 같이 바뀝니다 |
| **내려받기** | 바꾼 소리를 MP3 로 받습니다 |

```
「조만 바꾸기」는 원곡과 **길이가 같습니다.**
「빠르기 바꾸기」는 길이가 달라집니다.
무엇이 바뀌는지 화면에 적어 두었습니다.
```

---

## 안전

**파일이 기기 밖으로 나가지 않습니다.** 서버로 아무것도 보내지 않습니다.
브라우저 안에서만 소리를 바꿉니다.

---

## 속 — 바깥 라이브러리 0개

HTML 한 장입니다. 브라우저가 이미 가진 기능만 씁니다.

```
소리 읽기·쓰기   OfflineAudioContext · decodeAudioData · getChannelData
조만 바꾸기      WSOLA  (창 2048 · 건너뜀 512 · 찾는 범위 256, 한 창 겹쳐 잇기)
빠르기 바꾸기    playbackRate
MP3 로 내보내기  lamejs 를 파일 안에 넣어 두었습니다
```
